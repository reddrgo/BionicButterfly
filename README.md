# BionicButterfly
Mechanical robotic like butterfly that moves its wings which is made of copper so will the body be. The body will have an Arduino Nano which works as the brain for it the brain will work a servo connected to wires pulling the wings. Am still adding on to the whole project itself.


## Features

- Servo-powered wings
- Programmable RGB LED wing lighting
- Arduino Nano control
- Custom CAD designed in Onshape
